JARVIS V1.1.1 APK PROJECT

Files:
- main.py           -> complete app
- buildozer.spec    -> Android APK build configuration

Current features:
- Dashboard
- Rules
- Timetable
- Tasks
- Add task/rule
- Complete task
- Daily summary
- Date/time
- JSON persistence

Commands:
rules
timetable
tasks
summary
time
date
add task <your task>
add rule <your rule>
complete <number>
help

IMPORTANT:
This is the source project for building the APK. The APK itself must be compiled with an Android packaging environment such as Buildozer/python-for-android.
